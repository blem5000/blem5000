# Hi, I'm Grzegorz 👋

Network and systems administrator. I run Cisco networks and Windows servers for a manufacturing plant — and I build the monitoring and tooling that keeps both visible.

**Network** — Cisco IOS/IOS-XE routers and switches, ACLs and network segmentation, Check Point and Fortinet firewall policy management. I have led production and CCTV network separation projects end to end.

**Systems** — Windows Server and clients, Active Directory and Group Policy, WSUS, WDS/MDT imaging, Symantec Endpoint Protection, print services.

**Monitoring** — Zabbix is my daily driver: templates, discovery rules, items, triggers, dashboards, alert tuning and threshold work, plus a server and database migration and platform upgrades.

**Automation** — PowerShell first, then Python and C# when a script grows into a tool.

## Selected repositories

- **[cisco-acl-helper](https://github.com/blem5000/cisco-acl-helper)** — Windows GUI for managing ACLs on Cisco IOS/IOS-XE over SSHv2 (PL/EN).
- **[tactical-rmm-narzedzia](https://github.com/blem5000/tactical-rmm-narzedzia)** — administrative tooling for Tactical RMM: detecting and removing duplicate agents.
- **[Narzedzia-IP-2](https://github.com/blem5000/Narzedzia-IP-2)** — look up hosts in DHCP records and ping them in bulk.

Most of what I build lives inside the networks I administer, so these repositories are the smaller edge of it — utilities that solved a real, recurring annoyance.
